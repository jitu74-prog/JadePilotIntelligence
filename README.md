# 🖼️ Iframe Test Host Application

A hosted web application designed for testing iframe embedding of web portals and applications.

## 🌐 Live Demo

**Hosted URL:** `https://jitu74-prog.github.io/JadePilotIntelligence/`

## ✨ Features

- **URL Input**: Enter any web portal URL to load it in an iframe
- **Responsive Testing**: Switch between Desktop, Tablet, and Mobile views
- **Error Handling**: Shows helpful messages if iframe loading fails
- **Status Indicators**: Visual feedback on loading status
- **Modern UI**: Clean, professional interface with smooth animations
- **Publicly Hosted**: Available 24/7 for iframe embedding tests

## 🛠️ How to Use

1. Visit the hosted application URL
2. Enter your web portal URL in the input field
3. Click "Load Portal" to embed it in the iframe
4. Test different screen sizes using the view buttons
5. Use "Clear" to reset and test another URL

## 🎯 Use Cases

- **Iframe Compatibility Testing**: Test if your web portal can be embedded in iframes
- **Cross-Origin Testing**: Verify CORS and X-Frame-Options configurations
- **Responsive Design Testing**: Check how your portal looks in different viewport sizes
- **Integration Testing**: Test iframe embedding before implementing in production

## ⚠️ Important Notes

### Iframe Limitations
- Some websites block iframe embedding for security (X-Frame-Options)
- HTTPS sites may not load in HTTP contexts
- Cross-origin restrictions may apply

### Testing Tips
- Start with `http://localhost:PORT` if testing locally
- Check browser console for any error messages
- Try both HTTP and HTTPS versions of your portal
- Test with different screen sizes to ensure responsiveness

## 🔧 Technical Details

- **Framework**: Pure HTML, CSS, and JavaScript
- **Hosting**: GitHub Pages
- **Responsive**: Mobile-first design
- **Browser Support**: Modern browsers (Chrome, Firefox, Safari, Edge)

## 📱 Responsive Breakpoints

- **Desktop**: Full width (default)
- **Tablet**: 768px width
- **Mobile**: 375px width
